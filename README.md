# Nyahu AI

A lightweight AI chatbot powered by Google's Gemma.

I built this because I got tired of hitting message limits on almost every AI service. Instead of waiting for the quota to reset, I made my own.

Nyahu AI keeps things simple:

- Lightweight
- Fast
- Easy to use
- Easy to customize
- Self-host friendly

No fancy promises. Just an AI chatbot that works.

## Tech Stack

- Google Gemma
- Python
- Gradio
